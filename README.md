# tongbal

Rust library for the [Chzzk](https://chzzk.gitbook.io/chzzk) API.

## Crates

- [tongbal-api](https://crates.io/crates/tongbal-api) - API endpoints
- [tongbal-oauth](https://crates.io/crates/tongbal-oauth) - OAuth 2.0
- [tongbal-types](https://crates.io/crates/tongbal-types) - Shared types

## Chzzk API Coverage
